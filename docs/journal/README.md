# Journal

Dated learning notes for this repo — what was built, what broke, and what the
failure turned out to mean. One file per working session, named
`YYYY-MM-DD-<topic>.md`.

The split with [`../adr/`](../adr/): an ADR records a **decision** and the
alternatives rejected, and is meant to be read years later. A journal entry
records **what happened** on a given day, including the wrong turns. Decisions
get promoted out of the journal into an ADR; the journal keeps the story.

The system-wide journal lives in
[platform-control-plane/docs/journal](../../../platform-control-plane/docs/journal/).
